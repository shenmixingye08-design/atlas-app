# 【ATLAS機能評価】登録15分 Quick Win + 7日定着

機能名：登録15分以内の初回成果物保証と7日定着プラン

ユーザー価値：登録当日に「仕事が終わった」体験を必ず届け、7日で「このAIじゃないと困る」状態をつくる

差別化：チャット開始ではなく、実成果物（Word等）受領→Memory/Automationへ続く秘書体験

繰り返し作業の削減：はい — 初回設定・初回成果物作成・次の自動化選定の迷いと手作業を削減

AI必要度：低〜中 — 成果物生成のみ既存Activation/Deliverable経路。導線・計測・提案はルールベース

AIなしで実装可能：一部 — ウィザード・7日プラン・価値表示・アンケート・継続率は通常プログラム。成果物本文のみ既存生成経路

運営コスト：追加AI呼び出しなし（既存初回Activationを再利用）。localStorageメタデータのみ

外部APIコスト：無（成果物は既存経路。連携は希望収集のみで必須接続しない）

コスト削減案：

- [x] エコモードで足りるか — 初回はテンプレActivation、追加生成しない
- [x] まとめて生成できるか — Day1は1成果物に限定
- [x] キャッシュ再利用できるか — ウィザード回答・提案をlocalStorage再利用
- [x] 予約実行にできるか — Activation完了後に週次Automation登録（既存）
- [x] AI起動条件を絞れるか — 提案・Day判定はルール。AIは成果物時のみ
- [x] 外部APIの呼び出しタイミングを最小化できるか — 連携は希望収集のみ、必須接続しない
- [x] 完全自動ではなく承認後実行にできるか — 初回は「まず一度作ってみる」明示承認
- [x] 同じ処理を再生成しない設計にできるか — Activation完了フラグで再実行しない

優先度：P0
