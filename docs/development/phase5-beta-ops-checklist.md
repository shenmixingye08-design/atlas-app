# Phase5 — β版運営チェックリスト

**対象:** 招待制 10–20人  
**原則:** 新機能追加禁止。レビュー・推測で改善禁止。操作ログの実データのみ。  
**管理画面:** `/owner/beta-ops`（サービス状態。ユーザー一覧ではない）

---

## 公開前

### 法務・信頼

- [ ] `/terms` 利用規約が最新であること（確認日: ____）
- [ ] `/privacy` プライバシーポリシーが最新であること（確認日: ____）
- [ ] `/legal` 特商法表記が必要な項目を満たすこと
- [ ] フッターから規約・プラポリ・問い合わせ・不具合報告へ辿れること

### 招待・人数

- [ ] `ATLAS_BETA_USER_EMAILS` に 10–20 名のみ登録
- [ ] `/owner/beta-users` で招待リストが正しいこと
- [ ] 招待外アカウントで主要機能が開かない（またはβフラグで制限される）こと

### 導線（アンケートなし）

- [ ] 障害報告: `/contact?category=bug`
- [ ] フィードバック: `/contact?category=service`
- [ ] 問い合わせ: `/contact`
- [ ] 公開ステータス: `/status`
- [ ] ユーザーへ毎回アンケートを出していないこと

### 計測・障害

- [ ] `/owner/beta-ops` が今日/今週/今月を表示すること
- [ ] テスト依頼1件で完了率が動くこと（依頼→完了）
- [ ] `/owner/reliability` と `/owner/system-status` が開けること
- [ ] ジョブ失敗時にユーザーへ技術用語を出さないこと（秘書語）
- [ ] クラッシュは少なくともサーバログ／owner error monitoring で追えること（Sentry未導入でも運用可能）

### 公開判定（CEOゲート参照）

`/owner/beta-ops` の公開判定がデータ不足のまま無理に🟢にしないこと。  
正式公開は `docs/development/minervot-ceo-launch-gates.md` の n=50 基準。βは 10–20 で運営学習。

## 公開中（毎日 / 週次）

### 毎日（5分）

- [ ] `/owner/beta-ops` → **今日** の完了率・エラー率・平均時間
- [ ] 公開判定が🔴なら新規招待を止める
- [ ] `/contact` 不具合報告の未対応ゼロ化（または当日トリアージ）
- [ ] `/status` が実態と矛盾していないこと

### 週次（30分）

- [ ] **今週** KPIを前週と比較（完了率 / 離脱率 / 再実行率 / 7日継続）
- [ ] エラー上位原因をログだけで列挙（推測禁止）
- [ ] 改善する場合は人数・率の根拠を改善履歴に残す（`POST /api/owner/beta-ops`）
- [ ] 招待人数が 20 を超えていないこと

### 改善ルール（厳守）

| 禁止 | 許可 |
|------|------|
| レビュー感想での改修 | 完了率・失敗率など実KPIの悪化根拠 |
| 「たぶん迷う」 | 操作ログ上の離脱・再実行の増加 |
| 機能追加 | 文言削減・待機コピー・既存導線の摩擦除去のみ |

## 公開後（β終了 / 次フェーズ判断）

- [ ] **今月** KPIをスナップショット保存（スクショまたは改善履歴）
- [ ] 7日継続・30日継続・紹介率・課金率を記録
- [ ] Phase4 5人テストの優先ボードと矛盾がないか照合
- [ ] CEO Launch Gates（n=50）へ進むか、延期か、コンセプト中止かを数値だけで決定
- [ ] 招待制を外す判断はゲート合格後のみ

## 取得データ対応表

| KPI | 取得元 |
|-----|--------|
| 依頼数 | beta-ops `request` |
| 完了率 | complete / request |
| 失敗率 | fail / request |
| 平均完了時間 | complete.durationMs |
| 途中離脱率 | dropout（今後クライアント送信可） |
| 再実行率 | retry |
| 同じ仕事の再依頼 | assignmentHash 重複 |
| 7日/30日継続 | ユーザー別 request/complete の再訪 |
| 紹介率 | referral イベント（未計測時は —） |
| 課金率 | サブスク paid / (paid+free) |

## 運営メモ

- アンケートは出さない。必要なら問い合わせ導線のみ。
- クラッシュ専用SaaSは任意。まずはログと owner error monitoring。
- β中の正解は「静かにお仕事が終わること」。数字が悪ければ招待を止め、P0相当だけ直す。
