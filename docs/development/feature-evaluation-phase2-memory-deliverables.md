# 【ATLAS機能評価】

機能名：MINERVOT商品力改善 Phase 2（Memory適用と成果物の提出品質）

ユーザー価値：2回目から毎回の細かい指示が減り、Word/Excel/PDF/PowerPointを修正せず提出できる。

差別化：Memoryを「保存している」ではなく「次の仕事が短くなる」。成果物は開けるだけでなく、人に出せる。

繰り返し作業の削減：はい — 文体・長さ・見出し・ハッシュタグ・形式を毎回書かなくてよくなる。提出前の体裁直しが減る。

AI必要度：低 — 既存生成経路に Preference を適用する。新規AI機能は増やさない。品質判定は既存ゲート＋決定的検証。

AIなしで実装可能：はい — 指示の削減、Preference適用、品質ゲート、再取得検証は通常プログラム。生成本体は既存。

運営コスト：追加の定期AI呼び出しなし。Memory適用は既存 resolve。成果物検証はローカル決定的チェック。

外部APIコスト：無（新規）。既存の原稿生成・成果物生成のみ。

コスト削減案：

- [x] エコモードで足りるか — 既存エコモードは触らない。
- [x] まとめて生成できるか — 対象外。品質と適用の接続。
- [x] キャッシュ再利用できるか — 確定 Preference を再利用し、同じ指示を再生成しない。
- [x] 予約実行にできるか — 既存X自動投稿が Preference を毎回使う。
- [x] AI起動条件を絞れるか — 品質ゲート失敗時のみ既存リトライ。推測埋めはしない。
- [x] 外部APIの呼び出しタイミングを最小化できるか — 新規外部APIなし。
- [x] 完全自動ではなく承認後実行にできるか — 既存承認制を維持。
- [x] 同じ処理を再生成しない設計にできるか — Preference 適用後は再指定しない。

優先度：P0 — 2回目が楽にならない / 成果物が提出できないと有料価値にならない。
