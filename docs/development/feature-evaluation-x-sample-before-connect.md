# 【ATLAS機能評価】X連携前の「見本を1件つくる」

機能名：X連携前の投稿見本（`/workspace/x` 未連携時）

ユーザー価値：X連携（OAuth）の前に、自分のテーマで実際に毎日届く投稿の見本を1件見られる。「任せたら何が起きるか」が連携前に分かり、最初の関門（連携）を越える理由になる。

差別化：一般的なChat AIは毎回指示が必要。MINERVOTは「テーマを1回決めれば毎日これが投稿される」を連携前に体験させる。

繰り返し作業の削減：一部（本機能は体験用。削減は連携後の自動投稿で発生）

AI必要度：中（見本の質が購入判断に直結するため、既存の自動投稿と同じ生成を使う。LLM不可時は既存の決定的テンプレートにフォールバック）

AIなしで実装可能：一部（`buildFallbackAutoPost` のテンプレート見本は可能だが、実際の品質が伝わらない）

運営コスト：1回=軽量タスク（`worker_deliverable_light`、最大出力400トークン）。1ユーザー1日3回まで。未連携ユーザーのみ表示。

外部APIコスト：OpenAI のみ（従量）。X API は呼ばない（投稿しない）。

コスト削減案：

- [x] エコモード相当の軽量タスク種別を使用
- [ ] まとめて生成（1件で十分）
- [x] キャッシュ：生成結果はクライアントに保持し、同じ画面での再表示で再生成しない
- [ ] 予約実行（不要：体験用の即時生成）
- [x] AI起動条件：ボタン押下時のみ・テーマ入力必須・未連携時のみ
- [x] 外部API最小化：X APIは呼ばない
- [x] 承認後実行：投稿は一切しない（見本であることを明示）
- [x] 再生成制限：1ユーザー1日3回（分散レート制限 `x-sample` バケット）

優先度：P0（新規ユーザーの主導線の最大離脱点に対する施策。コストは1人あたり最大3回/日の軽量生成）
