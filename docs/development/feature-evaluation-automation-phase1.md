# 【ATLAS機能評価】Automation Phase 1 — 自然文から durable 自動化作成

機能名：自然文 → 永続スケジュール自動化（Phase 1）

ユーザー価値：チャットで「毎朝9時に…」と頼むだけで、フォーム操作なしに本物の定期仕事が登録され、Scheduler が実行対象にする

差別化：提案カードや「覚えました」表示で終わらず、DB 永続・active・nextRun まで一貫完遂する AI 秘書導線

繰り返し作業の削減：はい — 毎回フォームでスケジュールを手入力する習慣を減らす

AI必要度：低 — 繰り返し検出・スケジュール解析はルールで足りる。文章生成は実行時のみ

AIなしで実装可能：はい — 検出・parse・create・nextRun は通常プログラム

運営コスト：作成時 AI 追加呼び出しなし。実行時は既存 tick / orchestration と同コスト

外部APIコスト：無（作成時点）。実行時の外部連携は既存承認制御のまま

コスト削減案：

- [x] エコモードで足りるか（作成は AI なし）
- [x] まとめて生成できるか（該当薄）
- [x] キャッシュ再利用できるか（検出結果は決定的）
- [x] 予約実行にできるか（nextRun + Minute Scheduler）
- [x] AI起動条件を絞れるか（作成時 AI 不使用）
- [x] 外部APIの呼び出しタイミングを最小化できるか（作成時ゼロ）
- [x] 完全自動ではなく承認後実行にできるか（既定 approve_then_run、X も破壊しない）
- [x] 同じ処理を再生成しない設計にできるか（occurrence / idempotency 既存維持）

優先度：P0
