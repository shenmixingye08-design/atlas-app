# Phase6 — 正式公開判定システム

感覚・レビュー・推測は禁止。**実測数字だけ**で公開 / 延期 / 中止を決める。

管理画面: `/owner/launch-verdict`  
正本の閾値コード: `lib/owner/launch-verdict/thresholds.ts`

## 公開判定ルール

1. **すべてのKPIが「公開」基準**を満たした場合のみ → **正式公開（🟢）**
2. **1項目でも「延期」**（またはサンプル不足）→ **延期（🟡）**
3. **重大KPIが「中止」** → **公開禁止（🔴）**
4. 重大でないKPIの中止 → 正式公開不可。総合は**延期**
5. サンプル不足は数値があっても**延期扱い**（公開にできない）

### 最低サンプル

| 対象 | n |
|------|---|
| 仕事完了率 / エラー率 / 平均処理時間 | 依頼数 ≥ 50 |
| 初回成功率 / 継続 / 紹介 / 課金 | 該当ユーザー数 ≥ 50 |
| NPS | 回答数 ≥ 30 |

## KPI定義と基準値

### 初回成功率（重大）

ユーザーごとの**最初の依頼**が、最初の終端で `complete` だった割合。

| 判定 | 基準 |
|------|------|
| 公開 | 95%以上 |
| 延期 | 85〜94.9% |
| 中止 | 84.9%以下 |

### 仕事完了率（重大）

依頼数に対する完了数の割合（βイベント累計）。

| 判定 | 基準 |
|------|------|
| 公開 | 90%以上 |
| 延期 | 70〜89.9% |
| 中止 | 69.9%以下 |

### エラー率（重大）

依頼数に対する失敗数の割合。**低いほど良い。**

| 判定 | 基準 |
|------|------|
| 公開 | 2%以下 |
| 延期 | 2.1〜8% |
| 中止 | 8.1%以上 |

### 平均処理時間

完了ジョブの平均秒数。**低いほど良い。**

| 判定 | 基準 |
|------|------|
| 公開 | 180秒以下 |
| 延期 | 180.1〜420秒 |
| 中止 | 420.1秒以上 |

### 7日継続率（重大）

7–14日前に使ったユーザーのうち、直近7日に再訪した割合。

| 判定 | 基準 |
|------|------|
| 公開 | 40%以上 |
| 延期 | 20〜39.9% |
| 中止 | 19.9%以下 |

### 30日継続率

30–60日前コホートのうち、直近30日に再訪した割合。

| 判定 | 基準 |
|------|------|
| 公開 | 25%以上 |
| 延期 | 12〜24.9% |
| 中止 | 11.9%以下 |

### 紹介率

アクティブユーザーに対する紹介イベント数の割合。

| 判定 | 基準 |
|------|------|
| 公開 | 25%以上 |
| 延期 | 10〜24.9% |
| 中止 | 9.9%以下 |

### 課金率

課金サブスク /（無料+課金）サブスク。

| 判定 | 基準 |
|------|------|
| 公開 | 8%以上 |
| 延期 | 3〜7.9% |
| 中止 | 2.9%以下 |

### NPS（重大）

NPS = %Promoters(9–10) − %Detractors(0–6)。

| 判定 | 基準 |
|------|------|
| 公開 | 30以上 |
| 延期 | 0〜29.9 |
| 中止 | 0未満 |

## 改善ルール

- **数字が悪いKPIだけ**改善する
- 数字が良いものは触らない
- レビュー・感覚・推測で優先度を付けない
- 根拠は `/owner/launch-verdict` の実測のみ
