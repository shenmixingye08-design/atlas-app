# Phase2 — 画像→Word 品質レポート

**Scope:** 品質改善のみ（新機能追加なし）  
**Build context:** `cursor/phase2-image-to-word-quality-2159`

---

## 実施した改善（品質のみ）

1. **Vision構造理解** — `documentStructure`（title/heading/paragraph/bullet/numbered/table/page_break）をスキーマ・プロンプト・providerへ追加
2. **Word seed** — OCRダンプ禁止。構造→Markdown優先、弱いseedは自動repair
3. **完了パイプライン** — 最大3回サイレントリトライ、content QA + regenerator、テンプレート自動選択
4. **UX文言** — 進捗/失敗を「処理を続けています」等の秘書語へ（Word/Vision/AI解析を出さない）
5. **KPI** — `lib/vision/phase2-kpis.ts`（成功率・再生成率・構造ヒット・所要時間）
6. **100回テスト** — `lib/vision/phase2-image-to-word-100.test.ts`（合成画像構造→docx）

### 改善が必要な項目だけ

1. **ライブ画像100枚**での成功率・Vision所要時間・ユーザー修正率の実測  
2. **手書き・斜め・低照度**ケースの構造抽出精度  
3. **番号付きリストのネイティブnumbering**（現状は見た目の番号テキスト）  
4. 生成後の**レイアウト崩れ検出を文書モデル単位で強化**（欠落見出し・空表）

機能追加提案は行わない。

## Definition of Done（実装側）

画像理解 → 構造seed → 品質確認/修復 → Word生成 → 検証 → 保存可能URL — までを `completeImageWorkToDeliverables` がリトライ込みで完走。途中終了時もユーザー文言は「処理を続けています」。
