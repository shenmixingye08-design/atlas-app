## 1週間単位

### Week 1 — ホームを4要素に削る（本PR）

- [x] 成果物形式セレクタ削除
- [x] 挨拶・説明・添付UI・ヒントをホームから削除
- [x] 文言: MINERVOT / 何を終わらせますか？ / 任せる
- [x] Welcome / FirstExperience の自動表示を止める（`?welcome=1` のみ）
- [x] 進捗コピーを秘書語に統一
- [x] 完了を「お仕事が終わりました／こちらです／開く」

### Week 2 — 考えることをさらに減らす

- ホームでサイドバーを畳む（初回は本文だけ）
- 添付はラベル「画像」なし（ペースト/ドラッグのみ、必要な楔用）
- Workspace のクイックプリセット・形式語・WordProgress 露出を削除
- バックグラウンド待ち文面から「成果物」を削除

### Week 3 — 楔「画像→資料」の品質だけ

- 新機能禁止。既存 upload → vision → docx の失敗率を下げる
- タイムアウト・リトライ・エラー文を秘書語に
- 初回成功率を手計測（10件）

### Week 4 — 完了の正直さ

- 証拠なし completed を出さない（意図に無い送信は必須にしない）
- 「開く」= 主ファイル/プレビュー1つ
- KPI を README に固定し、機能数KPIを廃止宣言
