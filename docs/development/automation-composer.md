# Automation Composer（仕事を任せる）

## 減るユーザー作業

- 専門用語の理解・設定画面の探索
- 毎回の成果物・通知・好みの再入力
- 途中離脱によるやり直し

## 想定時間短縮

| | Before | After |
|--|--:|--:|
| 初回作成 | 5–15分（迷う） | **〜30秒**（テンプレ→任せる） |
| 2回目以降 | 毎回ゼロから | Memory / テンプレ再利用 |

## 7 Steps

1. 何を任せる（テンプレ）
2. いつ
3. 成果物
4. 知らせ方
5. 覚え方
6. くわしく
7. 確認して任せる（インライン編集 + Prediction）

専門用語（Workflow / Node / Trigger / Orchestrator / Execute）は UI に出しません。
