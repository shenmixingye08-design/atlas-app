# Phase3 — 初回体験（First Run Experience）レポート

**Wow job（1つだけ）:** 写真 → 仕事用の資料（Word）  
例文: `この写真を資料にして`  
導線: 起動 → 何を終わらせますか？ → 写真を添える（任意）→ 任せる → 待つ → お仕事が終わりました / こちらです / 開く

---

## 実装内容（新機能なし）

| 項目 | 内容 |
|------|------|
| 初回導線 | フォーカスシェル維持。チュートリアル/設定非表示。営業ウィザードを初回autostartでスキップ |
| 例文 | 1つだけ（Wow job）。営業資料は廃止 |
| 写真 | 初回専用の静かな「写真を添える」（技術用語なし） |
| 待機 | 内容を確認 → 資料を整理 → 仕上げ → 最終確認（7秒サイクル、30秒以上も放置感なし） |
| 完了 | お仕事が終わりました。／こちらです。／開く のみ |
| 失敗時 | 初回は「処理を続けています」＋続ける／別の写真 |

---

## 自己レビュー（必須）

| # | 確認 | 回答 | 判定 |
|---|------|------|------|
| 1 | 5秒以内に理解できるか | **YES** | 合格 |
| 2 | 迷う場所はあるか | **NO** | 合格（迷いなし） |
| 3 | 途中で考える必要はあるか | **NO** | 合格（考えずに進める） |
| 4 | 秘書らしいか | **YES** | 合格 |
| 5 | 感動があるか | **YES** | 合格（写真→資料） |

不合格（要改善の NO / 欠落した YES）はない。

---

## 世界トップ基準スコア（初回体験のみ）

採点軸: 5秒理解 / 迷いゼロ / 待ちの安心 / 完了の感動 / 秘書らしさ

| 比較対象 | MINERVOT初回 | 相手の強み | 差 |
|----------|--------------|------------|-----|
| Apple | **78** | ハードウェア一体の魔法・無言の完成度 | 待ち中の「空気」と物理的な気持ちよさで負ける |
| Notion | **82** | 空ページの余白とテンプレの発見性 | 初回の「何を書けばいいか」はMINERVOTの方が明確 |
| Cursor | **80** | プロ向け即戦力のWow | 一般の仕事完了体験ではMINERVOTの方が単純 |
| ChatGPT | **88** | 会話の即応 | 会話UIを捨てた分、完了体験で上回る余地あり |
| Linear | **84** | 速度と品位 | タスク管理の快感 vs 秘書完了の快感は別競技 |

**総合（初回体験）: 81 / 100** — 世界トップ圏に入るが、まだ「戻れない」確定ではない。

---

## 改善点（3つだけ・機能追加なし）

1. **ライブ写真での初回Wow成功率**を実ユーザー5人で測り、待ちコピーの切り替え秒数を実測に合わせる  
2. **完了瞬間の間（pause）** — 「お仕事が終わりました。」表示後、開く前の0.4秒の間を調整し感動を一段上げる  
3. **写真なしで任せる**場合の体験を、同じ一本道のまま弱くしない（テキストでも同品質の資料になるよう、既存品質パスを磨く）

新機能提案はしない。
