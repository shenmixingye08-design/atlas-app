# 【ATLAS機能評価】P1-08 成果物実用品質

機能名：成果物実用品質（Excel numFmt / PowerPoint 実表・画像埋め込み / Word 画像埋め込み）

ユーザー価値：生成した Excel・PowerPoint・Word をそのまま実務に使える品質で届き、「開けただけ・見た目が未完成」の手戻りがなくなる

差別化：チャットで文章を返すのではなく、セル書式・実テーブル・画像埋め込みまで秘書が仕上げる

繰り返し作業の削減：はい — 通貨/日付の手直し、表の貼り直し、ロゴ差し込みの習慣作業を削減

AI必要度：不要 — 既存の構造化ブロックを決定的にレンダリングするだけ

AIなしで実装可能：はい — exceljs numFmt / pptxgenjs addTable·addImage / docx ImageRun

運営コスト：追加 AI なし。生成 CPU のみ（既存成果物生成と同オーダー）

外部APIコスト：無

コスト削減案：

- [x] エコモードで足りるか — AI 不使用のため該当なし（低コスト）
- [x] まとめて生成できるか — 既存 multi-format export のまま
- [x] キャッシュ再利用できるか — 成功バイナリの品質欠落サイレント再生成はしない
- [x] 予約実行にできるか — 該当なし
- [x] AI起動条件を絞れるか — AI 起動しない
- [x] 外部APIの呼び出しタイミングを最小化できるか — 外部 API なし
- [x] 完全自動ではなく承認後実行にできるか — 決定的レンダリング（承認不要）
- [x] 同じ処理を再生成しない設計にできるか — 欠落時は失敗として扱い、成功扱いしない

優先度：P1（公開品質 / 優先度 B）

## Acceptance Criteria（正式・推測禁止）

47/100 評価および P1 再評価で定義された P1-08:

1. Excel: セル `numFmt`（通貨/日付をサイドカー文字列列にしない）
2. PowerPoint: 実テーブル（`addTable`）+ 実画像埋め込み（`addImage`。灰矩形プレースホルダ禁止）
3. Word: 画像埋め込み（`ImageRun`。ロゴ/画像を文言プレースホルダにしない）

PDF 表描画は P1-01 の責務（本項目で再実装しない）。
