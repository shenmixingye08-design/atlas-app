# MINERVOT CEO Launch Gates（数値のみ）

**役割:** CEO  
**対象:** 50人実験が完了した時点の経営判断  
**禁止:** 感覚、好み、「良さそう」、デザイン議論、実験設計の再議論  
**許可:** 下表の数値と判定式だけ

この文書が、正式公開 / 延期 / コンセプト作り直しの**唯一の判断基準**である。  
今後の経営判断は、ここに定義した KPI の実測値だけを見る。

---

## 0. 前提（固定）

| 項目 | 固定値 |
|------|--------|
| 判定コホート | n = 50（同一ジョブ・同一ビルド） |
| ジョブ | 画像または資料 → 仕事用文書が手元に残る |
| 完了の定義 | 研究者の手助けなしで、成果物を開く／保存できる（15分以内） |
| 計測期間 | Session0（当日実験）＋ Day7 フォロー（招待した完了者） |
| 課金計測 | Session0 完了者に対し、同一オファーを提示したときの有料転換（7日以内） |
| 小数 | 百分率は小数第1位四捨五入。判定は定義式の不等式をそのまま適用 |
| 欠測 | 必須 KPI が1つでも欠測なら **延期**（公開も中止も不可） |

## 1. KPI 定義（これ以外は使わない）

| ID | KPI | 定義 | 分母 |
|----|-----|------|------|
| K1 | **初回完了率** | Session0 で未補助完了した人数 ÷ 50 | 50 |
| K2 | **完了時間中央値** | 完了者の Session0 完了時間（秒）の中央値 | 完了者のみ |
| K3 | **継続率（Day7）** | Day7 に同じジョブクラスを自ら再完了した人数 ÷ Session0 完了者数 | Session0 完了者 |
| K4 | **紹介率** | Session0 で自発的紹介シグナル（薦めたい／送る／スクショ共有）が出た人数 ÷ 50 | 50 |
| K5 | **再利用意向（はい）** | 「二回目も使うか＝はい」÷ 50 | 50 |
| K6 | **課金率** | 7日以内に有料プランへ転換した人数 ÷ Session0 完了者数 | Session0 完了者 |
| K7 | **NPS** | `%Promoters(9–10) − %Detractors(0–6)`（Session0 終了直後、0–10） | 50 |
| K8 | **離脱・多選択肢率** | 閉じる理由が「何を書くかわからない」または「選択肢が多い」の人数 ÷ 50 | 50 |

**補助（公開判定には使わないが、延期時の単一改修ターゲット選定にのみ使用）**

| ID | KPI | 定義 |
|----|-----|------|
| A1 | 初回オンパス率 | 最初のタップが Input または 任せる ÷ 50 |
| A2 | 入力到達中央値 | 全参加者の入力開始秒の中央値（未入力は 900秒として中央値計算に含める） |

## 2. 判定ルール（優先順位）

上から順に評価する。**最初に該当した行が最終決定**。下の行は見ない。

1. **中止（コンセプト作り直し）** に該当 → 中止  
2. 該当せず **公開** に該当 → 正式公開  
3. どちらでもない → **延期**

同点や「惜しい」は存在しない。不等式のみ。

---

## 3. 正式公開基準（GO）

次を**すべて**満たす場合のみ正式公開する。

| KPI | 公開条件 |
|-----|----------|
| K1 初回完了率 | **≥ 80%** （≥ 40/50） |
| K2 完了時間中央値 | **≤ 180秒** |
| K3 継続率 Day7 | **≥ 40%** |
| K4 紹介率 | **≥ 25%** （≥ 13/50） |
| K5 再利用意向（はい） | **≥ 40%** （≥ 20/50） |
| K6 課金率 | **≥ 8%** |
| K7 NPS | **≥ 30** |
| K8 離脱・多選択肢率 | **≤ 15%** （≤ 7/50） |

**公開時にやってよいこと:** 広告・紹介・一般向け正式告知。  
**公開時にやってはいけないこと:** GO を理由にした機能追加ラッシュ。追加は別ゲート。

---

## 4. 延期基準（DELAY）

中止にも公開にも該当しない場合は、すべて延期。

加えて、次の**いずれか1つ**でも該当すれば延期（公開不可）。

| KPI | 延期トリガー |
|-----|----------------|
| K1 | **50% ≤ K1 < 80%** |
| K2 | **180秒 < K2 ≤ 420秒** かつ K1 ≥ 50% |
| K3 | **20% ≤ K3 < 40%** かつ K1 ≥ 50% |
| K4 | **10% ≤ K4 < 25%** かつ K1 ≥ 50% |
| K5 | **20% ≤ K5 < 40%** かつ K1 ≥ 50% |
| K6 | **3% ≤ K6 < 8%** かつ K1 ≥ 50% |
| K7 | **0 ≤ K7 < 30** かつ K1 ≥ 50% |
| K8 | **15% < K8 ≤ 35%** かつ K1 ≥ 50% |
| 欠測 | 必須 KPI（K1–K8）のいずれか欠測 |

**延期中の制約（数値オペ）**

- 変更は **1サイクル1箇所**  
- 改修ターゲットは、公開条件を満たしていない KPI のうち、公開閾値との差分が最大のもの1つ  
- 再計測は **同一ジョブで n=50**（または同一定義の n=20×2 独立コホートの合成が事前に定義されている場合のみ）  
- 延期サイクル上限: **3回**。3回後も公開未達 → 中止判定へ送る（§5 の「延期上限超過」）

---

## 5. 中止基準（KILL / コンセプト作り直し）

次の**いずれか1つ**で中止。現コンセプトでの正式公開は行わない。ジョブ定義・提供価値から作り直す。

| # | 条件（数値） |
|---|--------------|
| C1 | **K1 < 50%** （< 25/50） |
| C2 | **K3 < 20%** かつ **K1 < 70%** |
| C3 | **K4 < 10%** かつ **K1 < 70%** |
| C4 | **K5 < 20%** かつ **K1 < 70%** |
| C5 | **K6 < 3%** かつ **K1 < 70%** |
| C6 | **K7 < 0** |
| C7 | **K8 > 35%** （> 17/50） |
| C8 | **K2 > 420秒** かつ **K1 < 70%** |
| C9 | 延期サイクル **3回終了時点**で、§3 公開条件をすべて満たさない |

**中止後に禁止:** 同じジョブ・同じ価値命題での UI 微修正による再公開。  
**中止後に必須:** 新ジョブ定義 → 新 KPI ゲート文書 → 新 n=50。旧数字は引き継がない。

## 8. 経営運用ルール

1. 会議アジェンダは KPI 表のみ。感想タイムは設けない。  
2. 「あと少し」は延期であり公開ではない。  
3. 1つの KPI が公開ラインでも、他が中止ラインなら中止が優先。  
4. マーケ予算の増加は **正式公開決定後**のみ。  
5. 本ゲートの変更は、CEO 署名と「変更前コホートは旧ゲート適用」の明記が必要。ゲート改変で過去を合格扱いにしない。

## 9. 数値サマリー（壁貼り用）

### 正式公開（すべて必須）

- 初回完了率 ≥ **80%**
- 完了時間中央値 ≤ **180秒**
- Day7 継続率 ≥ **40%**
- 紹介率 ≥ **25%**
- 再利用「はい」≥ **40%**
- 課金率 ≥ **8%**
- NPS ≥ **30**
- 迷って閉じる率 ≤ **15%**

### 延期（代表）

- 完了率 50–79%、または他 KPI が公開未達かつ中止未満

### 中止（代表）

- 完了率 < **50%**
- NPS < **0**
- 迷って閉じる率 > **35%**
- または延期3回でも公開未達
