# 【ATLAS機能評価】

機能名：MINERVOT商品力改善 Phase 1（Lightで毎日のX投稿を完走可能にする）

ユーザー価値：月980円の推奨プランで、LPが約束する「毎朝のX投稿を一度頼めばあとは確認するだけ」が実際に完走する。Freeでも頼む→外部実行→完了を1回体験できる。

差別化：チャットAIではなく、一度頼んだ仕事を次から自動で終わらせる。第一ユースケースを毎日のX投稿に固定する。

繰り返し作業の削減：はい — 毎日のX投稿文作成・投稿・確認待ちを、初回設定以降は確認だけにする。

AI必要度：低 — 今回はEntitlement / LP / ホーム / 初回導線 / プラン説明の変更。原稿生成エンジンは既存。新規AI呼び出しは増やさない。

AIなしで実装可能：はい — 上限・表示・導線は通常プログラム。AIは既存の投稿文作成時のみ。

運営コスト：Lightは既存どおり AI 30回/月。Freeは AI 1 + X投稿 1 で上限固定。新規trial課金なし。

外部APIコスト：有 — X投稿APIは既存。Free 1 / Light 30 で server-side 上限。Stripe金額は変更しない。

コスト削減案：

- [x] エコモードで足りるか — 既存エコモードは触らない。今回はAI回数を増やさない。
- [x] まとめて生成できるか — 既存の定期実行を使う。新規まとめ生成は作らない。
- [x] キャッシュ再利用できるか — 既存Usage / Entitlementを再利用。
- [x] 予約実行にできるか — 既存X自動投稿の定期実行。
- [x] AI起動条件を絞れるか — 初回設定ではAIを呼ばない。実行時のみ既存経路。
- [x] 外部APIの呼び出しタイミングを最小化できるか — 投稿実行時のみ。接続はOAuth既存。
- [x] 完全自動ではなく承認後実行にできるか — 既存の承認制モードを残す。初回は保存まで。
- [x] 同じ処理を再生成しない設計にできるか — 上限到達後は再生成せず拒否。

優先度：P0 — 推奨プランでヒーロー仕事が完走しないと有料販売できない。
