# P13 成果物証明フェーズ

## 【ATLAS機能評価】

機能名：ホームページへの実際の完成見本（証拠）掲載

ユーザー価値：登録前に「本当に仕事が終わる」証拠を確認でき、登録・依頼の不安を減らす

差別化：会話デモではなく、SNS/メール/Word/Excel/PDFの完成見本を見せる

繰り返し作業の削減：一部 — 初見の「本当にできるのか？」確認作業を減らす

AI必要度：不要 — 既存ジェネレータで見本ファイルを事前生成。LP表示にAI呼び出しなし

AIなしで実装可能：はい

運営コスト：追加AI呼び出しなし（静的見本＋実測生成時間の固定表示）

外部APIコスト：無

コスト削減案：

- [x] エコモード — AI不使用
- [x] まとめて生成 — 見本は事前一括生成
- [x] キャッシュ再利用 — `public/samples` を再利用
- [x] 予約実行 — 該当なし（静的）
- [x] AI起動条件 — LP閲覧では起動しない
- [x] 外部API最小化 — なし
- [x] 承認後実行 — 該当なし
- [x] 再生成禁止 — 見本は再生成せず固定

優先度：P0（登録説得の証拠）

制約：架空KPI禁止。すべて「見本」と明示。作成時間は実測のみ。削減は手作業目安との差（見本定義）と明示。AIはモデル名ではなく MINERVOT の担当領域として表示（一人の秘書ルール）。
