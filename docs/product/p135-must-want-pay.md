# P13.5 「絶対使いたい」を作るフェーズ

## 【ATLAS機能評価】

機能名：980円を払う理由の構築（ストーリー・未来・毎日習慣・不安潰し・価格比較・初回60秒）

ユーザー価値：LPで「便利そう」ではなく「今すぐ使いたい／980円でも元が取れる」と判断できる

差別化：ChatGPTは答えが残る。MINERVOTは仕事が終わり、毎日の枠に入る

繰り返し作業の削減：はい — 毎朝SNS・毎日メール等の習慣作業を任せる理由を明示

AI必要度：不要（LP表示・初回導線文言のみ。新規AI呼び出しなし）

AIなしで実装可能：はい

運営コスト：追加AIなし

外部APIコスト：無

コスト削減案：静的見本・既存初回体験・既存手作業目安を再利用。再生成なし

優先度：P0

制約：デザイン改善・アニメ追加・機能追加ではない。架空KPI禁止。数値は見本目安／実測と明記。

## 辛口評価（改善後）

| 項目 | スコア | コメント |
|------|--------|----------|
| 仕事が終わる想像 | 7/10 | 4段ストーリーで想像可能。本番通知の実スクショはまだ弱い |
| 未来を買う感覚 | 7/10 | 朝の30分→戻る時間の物語あり。実ユーザー証言ゼロ |
| 毎日使う理由 | 7/10 | 習慣メニューを明示。習慣登録の実UI導線はLP止まり |
| 不安潰し | 7/10 | 4不安をLP上で潰した。第三者レビューなし |
| 980円の安さ | 6.5/10 | 比較は見本目安ベースで誠実。缶コーヒー換算は参考と明記 |
| ChatGPT差 | 8/10 | 「答えが残る／仕事が残る」対比を強化 |
| 登録60秒の感動 | 6.5/10 | 文言と導線は60秒完了を約束。品質はオーケストレーション次第 |
| **総合（自分なら980円払うか）** | **6.5/10** | 無料は即試す。980円は「毎日メールかSNSを任せるなら払う」まで来た。社会的証明が足りない |

### 1000人登録確率

- 改善前（P13時点）: 約18%
- 本P13.5後: **約28%**
- 50%には実ユーザー完成物・業種1本勝ち・登録後本番品質60秒が必要

### 残っている弱点

1. 実在ユーザーの「元取れた」証言がない  
2. 習慣自動化の設定がLPから見えず、毎日使う確信が弱い  
3. 初回体験がデモ品質だと信頼が折れる  
4. 対象がまだ広い（個人事業主＋会社員）  
5. 無料→980のアップグレード瞬間の説得がアプリ内に弱い

## 改善前後比較（要約）

| 観点 | Before | After |
|------|--------|-------|
| LPの役割 | 何をするか説明 | 980円を払う決断材料 |
| 証拠 | 成果物一覧 | 依頼→作業中→通知→完成の物語 |
| 感情 | 薄い | 朝の分が戻る未来 |
| 毎日 | なし | SNS/メール/資料/報告書の枠 |
| 不安 | 残る | 4つをLP上で潰す |
| 980円 | 料金表 | 缶コーヒー・戻る時間と比較 |
| ChatGPT差 | 答える/終わる | 別カテゴリ表 |
| 登録後 | 説明寄り | 60秒1件・元が取れた完了文 |

## なぜ登録率が上がるのか

「あとで」の原因（想像できない・不安・価格が高い・毎日使う理由がない）を、LP上の具体ストーリーと見本計算で先に潰したから。CTAも「無料で試す」から「今すぐ1件終わらせる」へ変更。
