# MINERVOT Phase0 — 開発憲法（絶対ルール）

> **最上位ルール:** [`MINERVOT_CONSTITUTION.md`](./MINERVOT_CONSTITUTION.md)  
> これに反する実装は禁止。機能追加より原則を優先する。

MINERVOTはAIサービスではありません。  
**「仕事を最後まで終わらせるAI秘書」** です。  
ユーザーはAIを操作したいのではなく、仕事を終わらせたいだけです。

### 開発原則（要約）

1. **手段を考えさせない** — Word / PDF / Excel / 画像解析 / AIモデルは内部実装。ユーザーへ見せない。
2. **仕事完了率が上がらない機能は作らない** — 評価は仕事完了率だけ。
3. **秘書として振る舞う** — 「Word生成中」禁止。「内容を確認しています」「資料を準備しています」「仕上げています」。
4. **Done = 仕事が終わること** — 成果物生成だけでは Done ではない。
5. **迷ったら削る** — 画面・ボタンは増やす前に減らす。
6. **数字で判断する** — 完了率 / 成功率 / エラー率 / 継続率 / NPS / 紹介率のみ。感想禁止。
7. **AIを見せない** — ユーザーが見るのは仕事だけ。
8. **初回5分以内に価値を証明する** — 不要なものは削除。
9. **ChatGPTを真似しない** — 会話UIではなく、仕事完了の導線。
10. **実装前に YES×5** — 考えることが減る / 完了率が上がる / 秘書らしい / 画面が減る / 初回体験が良い。揃わなければ実装しない。

### フェーズ（順番厳守・飛び越し禁止）

| Phase | 内容 |
|-------|------|
| 1 | ホーム画面の極限シンプル化 |
| 2 | 画像→文書の成功率・速度・品質改善 |
| 3 | 実ユーザー5名テスト |
| 4 | 50名実証 |
| 5 | KPI判定 |
| 6 | 正式公開 |

すべての PR で憲法自己レビュー必須（`.github/pull_request_template.md`）。違反時は理由を明記。

# ATLAS / MINERVOT

**あなた専属のAI秘書**（ユーザー向けブランド: MINERVOT）

ATLAS / MINERVOT はAIチャットサービスではありません。会話ではなく、お客様の時間を生み出すことを目的とした専属AI秘書です。

> **ルール優先順位:**  
> 1. [`MINERVOT_CONSTITUTION.md`](./MINERVOT_CONSTITUTION.md)（最上位・絶対）  
> 2. [`ATLAS_RULES.md`](./ATLAS_RULES.md)（口調・用語・進行の詳細）  
> 3. `AGENTS.md` / `docs/development/`  
> 矛盾する場合は上位を正とする。

## 使命

- 仕事を記憶する
- 習慣的な作業を覚える
- 資料を整理する
- 分析する
- 改善案をご用意する

画像生成や動画生成は目的ではありません。仕事を完了するための手段として扱います。

## 提供する価値

- **時間** — 繰り返し作業を減らし、お客様の時間を生み出す
- **効率** — 依頼から完了・保存までを一気通貫で進める
- **記憶** — 仕事の好み・習慣を覚え、次回から最適化する
- **継続** — 定期業務を忘れずに実行し続ける
- **分析** — 状況を整理し、改善案を提示する

AIらしさではなく、**人間の負担を減らすこと**を最優先します。

## 機能追加の判断基準

新しい機能を追加するとき、必ず以下を判断基準にしてください。

> **「この機能は、お客様の習慣的な作業を減らせるか？」**  
> かつ憲法 原則10 の YES×5 が揃うか。

- **YES** → 追加を検討（現フェーズ内に限る）
- **NO** → 追加しない

## AI人格・口調

詳細: `docs/atlas-personality.md` / `lib/atlas-personality/`

- 落ち着いた一流秘書の口調（かしこまりました、ご確認をお願いいたします 等）
- 会話ではなく仕事・習慣・資料を記憶
- 雑談のみの場合は丁寧に本来の目的へ誘導

## 仕事の記憶（Work Memory）

詳細: `docs/work-memory.md` / `lib/work-memory/`

- ユーザーごとに完全分離された業務記憶基盤
- 7 分類（workflow / preference / template / habit / correction / result / outcome）
- 依頼時の関連記憶注入、候補→確認→確定フロー
- 管理画面: `/settings/work-memory`

## 経験学習（Learning Engine）

詳細: `docs/learning-engine.md` / `lib/learning-engine/`

- Work Memory 上位の分析・改善提案エンジン
- 30/90/180/365 日またはユーザー依頼時のみ分析
- 仕事完了時はイベント記録 + 記憶候補のみ（分析なし）
- 管理画面: `/settings/learning`

## 開発

```bash
npm install
npm run dev
npm run build
npm test
```

詳細な開発ルールは [`MINERVOT_CONSTITUTION.md`](./MINERVOT_CONSTITUTION.md)（最上位）、[`ATLAS_RULES.md`](./ATLAS_RULES.md)、`AGENTS.md`、および `docs/development/` を参照してください。
